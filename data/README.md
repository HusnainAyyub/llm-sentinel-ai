# Dataset

Target: 2,000 prompts, 500 per category.

Categories: benign, jailbreak, direct injection, indirect injection.

Split: 70/15/15 train, validation, test (1,400 / 300 / 300 total, 350 / 75 / 75 per category).

Format: CSV with two columns, `prompt,label`.

`sample_prompts.csv` is a small starter set so the code runs before the full dataset is collected.
